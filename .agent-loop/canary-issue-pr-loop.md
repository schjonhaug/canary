# Canary Issue Prompt

The [Canary issue loop skill](../.agents/skills/canary-issue-loop/SKILL.md) is the maintained workflow. Start it with:

```text
Use .agents/skills/canary-issue-loop/SKILL.md to work on GitHub issue #ISSUE_NUMBER in this Canary checkout.
```

For local-only work, add `Do not open a PR.`
